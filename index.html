Flagship Project

Watchario

Sole engineer · Live in production

A self-hostable media-tracking product that keeps four third-party services in lockstep, delivered as three client surfaces on one .NET 10 codebase: a Blazor web app, a Stremio addon, and a cross-browser extension — with an Android build heading to Google Play.

  • Designed the whole system — ASP.NET Core, Blazor Web (SSR + WebAssembly) and .NET MAUI sharing one component library.
  • 213 REST endpoints designed, versioned and documented with OpenAPI; the browser extension is built entirely against that public API.
  • OAuth 2.0 against four providers — authorization-code, PKCE and password grants — with token refresh and per-provider lazy re-auth.
  • Concurrent write fan-out that mirrors every update across linked accounts, normalising status and score between incompatible provider models.
  • Runs itself — Docker on Fly.io, SQLite with continuous Litestream replication, a rehearsed restore drill, and three Cloudflare Workers.
  • Billing and entitlements through Paddle webhooks, made idempotent so retries and duplicate deliveries cannot double-charge or double-grant.
